# 法则

这些法则用来核对刚写好的 `strategy.md`。人在观察页里维护这一局的法则。agent 不要改它。改过的上一份留在这一局的 `agent/rules/` 里。

写完策略、还没有下令之前，按下面每一条做。先看「何时生效」。对不上这个条件，就在法则核对里写「未生效」。生效了，就用「必须」和「不能」对照这一份策略。有一条不通过，相关的那个目标算对不上，期限没到也要改写，并写上新的回合；这一回合的做法跟着改。改完再核对，最多改两轮。全部生效的法则都通过之后，才能按策略下令。

核对写在 `strategy.md` 末尾，标题用「法则核对」。每一条写：名称、生效或未生效、通过或已改哪一个目标。

## 先看局面再下令

何时生效：每一回合。

必须：按现在的画面写这一回合的做法。对话框还开着就先回答，再做别的。

不能：停在对话框上不选、也不结束回合。不能写画面上做不到的事。
